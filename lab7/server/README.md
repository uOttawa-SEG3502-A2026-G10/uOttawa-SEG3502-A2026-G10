# SEG3502 — Lab 7 — Serveur Spring Boot

API REST Spring Boot/Kotlin utilisée par le client Angular du laboratoire 7.

Le serveur utilise Java 17 et MySQL configuré dans `src/main/resources/application.properties`.

Démarrage :

```bash
./gradlew bootRun
```

Sous Windows :

```text
gradlew.bat bootRun
```

URL de base : `http://localhost:8080/books-api`
