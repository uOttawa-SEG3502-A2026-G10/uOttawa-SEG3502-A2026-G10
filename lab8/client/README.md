# SEG3502 — Lab 8 — Client Angular

Application Employee fournie pour le laboratoire 8.

Le client est déjà configuré pour communiquer avec le serveur GraphQL à :

```text
http://localhost:9000/graphql
```

Démarrage :

```bash
npm install
npm start
```

Puis ouvrez `http://localhost:4200`.

Le livrable du laboratoire porte sur la complétion du serveur GraphQL; ne remplacez pas ce client par le code de solution.
